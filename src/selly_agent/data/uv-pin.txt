# Read by ./setup (POSIX sh, before any interpreter exists) and by
# selly_agent/installer/runtime.py. Both parse it line by line, so this stays plain data —
# never shell to source, because sourcing a file is running it.

# Digests are recorded here rather than fetched next to the download: a checksum served by
# whoever served the archive vouches for nothing. Bumping uv means editing this file, which
# makes it a reviewed diff.

# own build knows about, and an older uv will quietly hand back a pre-release instead of the
# version in .python-version. Do not lower this without checking `uv python list`.
#
#   version <uv version>
#   sha256  <rust target triple> <digest>
